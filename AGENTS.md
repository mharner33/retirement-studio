# Retirement Studio

Retirement Studio is a retirement analysis and planning tool. Its goal is to assist users planning for retirement by analyzing the current status, examining the current IRS rules and modeling various scenarios to provide an optimal plan which will reduce tax liabilities and optimize spending over the expected lifespan of the retiree.

### Start here

IMPORTANT: before you plan, build or change anything in the product, or answer questions about it, read each of these files in full:

### Folders

- `docs/`: the main documentation for the product build
- `backend/`, `agent/`, `dashboard/` and `e2e/`: the product
- `data/`: directory for users retirement documents (401K, IRA etc) as well as any IRS retirement rules
